# KV Store

Небольшое консольное хранилище на C++20. Оно позволяет сохранять строки в виде пар «ключ — значение», получать их по ключу и удалять.

Проект учебный. В нём я разбираюсь с работой с файлами, хранением данных и синхронизацией потоков.

## Что умеет программа

- Добавлять и изменять значения по ключу.
- Читать сохранённые значения.
- Удалять записи.
- Восстанавливать состояние хранилища после перезапуска.
- Убирать устаревшие записи из файла командой `COMPACT`.
- Проверять записи с помощью контрольной суммы CRC32.

## Как это работает

Данные хранятся в файле `database.txt`. Несмотря на расширение, это бинарный файл, поэтому редактировать его как обычный текст не нужно. Файл создаётся при первой записи в текущей рабочей папке программы.

При добавлении или изменении значения новая запись дописывается в конец файла. Старую запись программа сразу не удаляет. Для удаления ключа в конец файла добавляется отдельная запись об удалении.

В памяти хранится таблица с ключами и позициями их актуальных записей в файле. Благодаря этому для получения значения не нужно каждый раз читать весь файл. При запуске программа читает записи по порядку и заново собирает эту таблицу.

Команда `COMPACT` записывает актуальные данные во временный файл, а затем заменяет им основной. Это позволяет убрать старые значения и записи об удалении.

## Сборка

Проект рассчитан на Windows: для замены файла при уплотнении используется Windows API.

Понадобятся:

- Visual Studio 2022 с компонентами разработки на C++;
- CMake 3.20 или новее;
- установленный vcpkg.

Для тестов используется GoogleTest. Зависимости перечислены в `vcpkg.json`.

Открой PowerShell в папке проекта и выполни:

```powershell
cmake -S . -B build -DCMAKE_TOOLCHAIN_FILE=C:/dev/vcpkg/scripts/buildsystems/vcpkg.cmake
cmake --build build --config Debug
```

Если vcpkg установлен в другой папке, укажи свой путь в первой команде.

Запуск программы:

```powershell
.\build\Debug\kv_store.exe
```

## Команды

Ключи и значения нужно писать в двойных кавычках.

| Команда | Действие |
|---|---|
| `PUT "key" "value"` | Добавляет значение или заменяет существующее |
| `GET "key"` | Выводит значение по ключу |
| `DELETE "key"` | Удаляет ключ |
| `COMPACT` | Перезаписывает файл, оставляя актуальные данные |
| `EXIT` | Завершает программу |

Пример работы:

```text
PUT "name" "Damir"
GET "name"
PUT "name" "Dima"
GET "name"
DELETE "name"
COMPACT
EXIT
```

Первый `GET` выведет `Damir`, а второй — `Dima`. После `DELETE` ключа `name` в хранилище не будет.

Пробелы внутри значения допустимы:

```text
PUT "note" "Learning C++"
GET "note"
```

## Тесты

После сборки запусти:

```powershell
ctest --test-dir build -C Debug --output-on-failure
```

Тесты проверяют запись и чтение, обновление и удаление значений, восстановление после перезапуска, работу нескольких потоков и сохранение данных после `COMPACT`. Также проверяется запрет дальнейших изменений после ошибки записи.

## Ограничения

- Пустые ключи и значения не поддерживаются.
- Максимальный размер ключа — 64 КиБ, значения — 16 МиБ.
- В командах пока нет экранирования двойных кавычек.
- Несколько потоков могут работать с одним объектом `KVStore`. Открывать один файл через несколько независимых объектов или процессов нельзя: такая работа не поддерживается.
- При уплотнении все актуальные значения временно загружаются в память, а остальные операции с этим объектом ждут завершения.
- Если последняя запись оборвалась, при следующем открытии программа удаляет незавершённый хвост. Другие обнаруженные повреждения, например несовпадение CRC32, приводят к ошибке открытия.
- После ошибки записи дальнейшие изменения блокируются до повторного открытия хранилища.
- Принудительного сохранения данных на физический диск пока нет, поэтому сохранность последних изменений при отключении питания не гарантируется.

Это учебное хранилище, а не готовая замена полноценной базе данных.
